- **作ったもの**:
  - React を使わない部分は `src/bulkDraft.ts`(枠を作る `createFrames`・枠か `isFrame`・中身を作る `generateFor`・書き込む `applyResult`・確認した `markChecked`)。画面の状態と操作は `src/useWeekFrames.ts`(App が持つ)。画面は、帯 `src/FrameBar.tsx`、週の列の枠 `src/FrameCard.tsx`、確かめる引き出し `src/CheckDrawer.tsx`。週の表示(`WeekView`)には、配信の描き方の差し替え(`renderCard`)と、未確認の印を押したとき(`onCheck`)を足しただけ。
  - AI の作り方は、配信カードの「すべてAIで下書き」と同じ `runAutoDraft`(`src/autoDraft.ts`)をそのまま使う。保存も、配信カードの保存と同じ形(あとで開いて直しても、1 本ずつ作ったものと見分けがつかない)。配信名・種類は `AiCard` の `name`・`themeType` で渡す。配信名の案は `suggestNames`(`src/aiDraft.ts`)。
  - 配信カード(`CardDetail`)は、未確認の印があれば知らせを出し、保存すると印を外す(`buildContent` に `ai_unchecked_at: null`)。
  - **確かめていないこと**: 撮影・デモ用のビルドの AI(`src/mock/agent.ts`)は、避けるテーマ・配信名・種類を見ない(配信名の案も、決まった形で返す)。本物の Gemini で、テーマが重ならないか・配信名と種類に沿うかは、まだ確かめていない。
  - 気をつけること: 枠かどうかは「未起案で中身がない」で見分けるので、ほかの方法で作って中身がまだない配信も、週の表示では枠として出る(配信名・種類を入れて、中身を作れる)。
- **経緯(2026-10-16。どれも利用者の指摘)**:
  1. 最初は、右上の「＋ 新規作成 ▾」から開くパネル。行ごとに日付・国・チャネル・種別を選び、AI で中身まで一度に作り、パネルの中で保存した。
  2. 1 回目の見直し: 使われ方は「週単位で、国・チャネルを決めて、まとめて作る」がほとんど。入口を週の状態の帯に移し、国・チャネルを最初に 1 回だけ選ぶようにした。
