# ルール集: 表現と選定の決まり(見本)
- 版: 2026-10-17
- 出どころ: 見本(docs/POLICY_FORMAT.md の 3 章の書き方で書いた、架空の決まり。利用先の文書から作るときの手本)

## R-COPY-001 価格は税込みで書く
- 対象: copy, headline
- 強さ: must
- 市場: JP
- 確かめ方: 含めない /\d[\d,]*円(?!\s*[(（]税込)/

価格を書くときは「1,980円(税込)」のように、税込みであることを添える。

## R-COPY-002 最上級と断定を使わない
- 対象: copy, headline, instructions
- 強さ: must
- 確かめ方: 含めない 最高, 最安, 業界No.1, 絶対, best ever, cheapest

「最高」「最安」「絶対」のような、裏づけのいる言い切りは使わない。比較するときは、何と比べたかを書く。

## R-SEL-010 新作の配信に、在庫調整の商品を入れない
- 対象: selection
- 強さ: must
- 確かめ方: 除く 段階=在庫調整
- 期間: 2026-10-01 - 2026-12-31

新作・新入荷のテーマの配信では、在庫調整の商品を選ばない(値下げの印象が、新作の価値を下げるため)。

## R-SEL-011 メールの上位の枠は、在庫に余裕のある商品に
- 対象: selection
- 強さ: should
- チャネル: email

メールの最初のセクションには、在庫が十分にある商品を置く(配信直後に売り切れると、問い合わせが増えるため)。

## R-TONE-001 口調は、落ち着いた丁寧語
- 対象: headline, copy, instructions
- 強さ: should

あおる表現(「今だけ!」「急いで!」の連続)は避け、落ち着いた丁寧語で書く。感嘆符は、1 つの文章に 1 つまで。

## R-HERO-001 メイン画像は、人物の顔が切れないもの
- 対象: hero
- 強さ: should

人物が写るメイン画像は、顔が枠で切れないものを選ぶ。

## R-BG-001 秋冬の主な顧客像
- 対象: theme, copy
- 強さ: info
- 市場: JP

秋冬は、30〜40 代の既存会員の再購入が売上の中心。新規の獲得より、着回し・買い足しの提案が効く。

## R-SCH-001 同じ商品は週 2 回まで
- 対象: schedule
- 強さ: must
- 確かめ方: 上限 週 2 回

同じ商品を、同じ週に 3 回以上は載せない(露出の偏りを避ける)。
