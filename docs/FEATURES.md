# 機能説明

「Campaign Contents Planner(CCP)」の機能の説明。
画面の用語は、実際の画面の表記(日本語 / English)に合わせてある。**「未実装・制限」の章に書いたことは、できないこと。**
機能ごとの「なぜその機能があるか」は、[FEATURE_REASONS.md](FEATURE_REASONS.md)(機能の理由の台帳)を参照。

---

## 1. 一言で

メール・アプリの**配信コンテンツ**(テーマ、メイン画像、ヘッドライン・コピー、セクションごとの商品、制作指示)を、**AI の提案を選びながら**企画し、**週ごとにレビュー・承認**し、送ったあとの**結果を振り返る**アプリ。
配信前には、在庫切れや方針の変更などの**アラート**で、事故を防ぐ。US チームと JP チームが、日本語・英語のどちらでも使える。

## 2. 解決する課題と、価値

| 課題 | このアプリでの解決 |
|---|---|
| 企画の素案づくりに時間がかかる | 「すべてAIで下書き」で、テーマから制作指示まで一度に下書きを作る。週の表示で、週の枠を作って配信名と種類を入れ、まとめて AI で中身を作ることもできる |
| 商品の選定が属人的 | 在庫・売上トレンド・評価・季節・天候などを踏まえた AI の選定と、**その理由**を表示する |
| 国ごとに、商品・言語が違う | 配信カードの「国」(US / JP)に合わせて、商品・画像・コピーの言語を使い分ける |
| デザイナーが、商品情報を探し回る | 商品情報ペインで、掲載商品の情報を一覧し、売上・在庫の推移や MD の方針も見られる |
| メールの構成を、毎回、作り直す | テンプレート(構成の型)を選ぶ。自分でも作って、チームで共有できる |
| AI の案が、気に入らない | チャットで指示を足して、案を作り直す(「この商品を必ず入れて」など) |
| 週の計画のレビューが、資料づくりと確認で重い | 週の表示で 1 週間をまとめて見て、確認の一覧(同じ商品の回数・主力の漏れなど)・コメント・承認までを同じ画面で行う。資料は PDF で書き出す |
| 配信のあとで、在庫切れや方針の変更に気づく | 配信前の在庫の見込みと、方針・日程の変更を**アラート**で知らせ、差し替え・延期・取りやめまでその場で対応する |
| 振り返りが、次の企画に生きない | 結果をカレンダー・一覧・ヒートマップで振り返り、「次に生かすメモ」を、次の配信カードと AI の案に渡す |

**人が決める、AI は提案する**、という立場。AI の案は、**採用するまで反映されない**(一部は、反映して「元に戻す」で戻せる)。

## 3. 想定する利用者

- **企画担当(販促・CRM・EC)**: 配信を企画し、AI の案を選んで、内容を決める。週の計画をレビューに出す。
- **レビュー・承認する人**: 週の計画を見て、コメントを残し、承認・差し戻し・週の確定をする。
- **デザイナー・制作担当**: 決まった内容(ヘッドライン、コピー、商品、制作指示、リンク先)と商品情報を見て、制作する。質問を返す。
- **MD(商品担当)**: 商品の販売方針・販促計画を、AI の選定と制作の判断に使えるようにする(データとして登録されている)。
- 国: **US チーム / JP チーム**。

## 4. 画面の流れ

### 4.1 ヘッダーと、共通のツールバー

- **いまどの面にいるか**: 面ごとの色(計画 = 藍、制作 = 橙、結果 = 緑。メールとアプリの札の青・ベリーとは重ねない)。ヘッダーのすぐ下に、面の色の細い帯と、ロゴ風の面の名前(PLAN / PRODUCTION / RESULTS)と一言の説明。面の切り替えで選んでいる側も、面の色。配信カード・制作のページ・詳しい結果の題名の左に、同じ色の面の札。

- **リンクで画面を伝える**: 面・見せ方・期間・国と、開いているフロート(配信カードとその工程のタブ・詳しい結果・アラートの商品・制作のページ)を、URL に持たせる。フロートの右上の「**リンクをコピー**」で写して送ると、相手も同じ画面で開ける。ブラウザの「戻る」でフロートが閉じ、再読み込みしても開いたまま。リンクの国は、そのときだけ合わせる(ふだんの国の設定は変えない)。リンクの配信が見つからなければ、知らせていつもの画面で開く。

- ヘッダー: アプリ名、**国**(「すべての国 / US / JP」。どの国の仕事をしているか。画面のすべて(計画・結果・週の帯・アラート・依頼の件数・新規作成の既定の国)に効き、人ごと(ブラウザごと)に覚える。全体を見る人は「すべての国」)、「**アラート**」(未対応の件数。在庫切れがあれば赤)、「**依頼**」(自分宛ての承認の依頼)、「**＋ 新規作成 ▾**」(本体で 1 本作る。▾ から「**まとめて作る**」(作業画面。5.1.1)と「**この週の枠を作る**」(週の表示の上で作る、これまでの形。5.1.2))、「**あなた**」(履歴・依頼・承認に残す人。ユーザーが登録されていれば選んで切り替え(デモ)、「**ログアウト**」で最初の「だれでログインしますか?」に戻る。1 人も登録されていなければ名前の入力)、**⚙**(システム全体の設定: テンプレートの管理・ユーザーと承認グループ(承認の決まりもここ)・方針と決まり・BigQuery からの取り込み・商品・カテゴリの指標の取り込み(CSV)・外部広告の見本を作る・種類が未設定の配信を AI で分ける・データと画像の書き出し・言語・開いたとき自動で下書き)。
- ツールバー(計画・制作・結果で共通。切り替えても、期間・見せ方・絞り込みはそのまま):
  - 作業の段: ヘッダー(システム全体)のすぐ下の段の左端に **[計画 | 制作 | 結果]** の切り替え、その右に絞り込み。
  - 絞り込み: 作業の段に、**チャネル / 種類 / ステータス / 担当** の札を横に並べる(ステータスは計画の面だけ。国はヘッダーの国)。選んでいない札は名前だけ(「チャネル ▾」)、選ぶと「チャネル: メール ▾」と中身を出して色が付く。絞っているときだけ「クリア」。**種類**はテーマの種類(値下げ / 期間限定価格 / セール / 新作 / コラボ / 会員向け / 季節の特集 / 再入荷 / その他。決まっていない配信は、言葉から推し量った種類で見る)。担当のいちばん上は「**自分**」(右上でログインしている人。切り替えると追いかける)。担当は、企画・制作の担当か、質問・タスクの宛先。
  - 期間: ‹ › で移動。期間の文字(例: 2026年10月)を押すと**ミニカレンダー**が開き、月・週・日へ移れる。
  - 見せ方: **[月 | 週 | 一覧 | 商品別 | 比べる]**(「比べる」は結果の面でだけ押せる。商品別は 4.5.1)。計画の面の週のときは「週の見方」(**商品 / 進み具合 / 時刻**。結果の面では出さない)。「**時刻**」は、横 = 曜日・縦 = 時刻の格子に配信を配信時刻の位置で置き、違う日で同じ時刻の配信に点線を引き、左の時刻の列に「10:00 ×4」の札を出す(マウスを重ねると「10:00 の配信が 4 日あります」)。カードにマウスを重ねるとプレビュー。カードをつかんで別の日・時刻へ動かせる(15 分きざみ。「元に戻す」あり。承認済み・確定した週・取りやめの配信は鍵の印で、配信カードで変える)。
  - ツールバーの右端に「**この画面 ▾**」: いま見ているものへの操作をまとめたメニュー(どの面・見せ方でも同じ位置)。計画: この週の枠を作る(週の表示)・この月の空いている週から、枠を作る(月・一覧。配信がいちばん少ない確定前の週に移って始める)・配信を CSV で書き出す(表示中の月・週)・週の資料を PDF で書き出す・この週の承認の履歴(週の表示のとき)・表示する列(一覧のとき)。結果: 結果の CSV の書き出し・結果の取り込み・取り込みの見本・AI でテーマの種類を分ける。
- 国: US / JP。チャネル: **メール / アプリ**。種類: テーマの種類(上の絞り込みと同じ)。
- ステータス(4段階・色分け): **未起案 → 検討中 → 承認済み → 確定**。

- **表示の大きさ**(右上の「あなた」のメニュー): 小さめ(80%)/ やや小さめ(90%)/ 標準 / 大きめ(110%)。文字も部品もまとめて縮める・広げる(ノート PC など、画面が狭いときに作業の領域を広げる)。このブラウザで覚える。
### 4.2 計画の面

- **月**: カレンダーに配信が並ぶ。1 行目はチャネルの印と名前、2 行目は時刻と国。**ステータスの色**(左の線と薄い色)で状態が分かる。メールとアプリは、名前の前の**塗りつぶしの印**(メール = 青の地に白い封筒、アプリ = ベリー色の地に白いスマートフォン)で見分ける。
  - 印: アラートのある配信、配信日が近いのに未着手の配信、取りやめた配信(取り消し線で薄く)。
  - 各週の先頭(日曜日)の「**週 ›**」を押すと、その週の週表示に移る(結果の面でも同じ)。
  - 上に「**月の要約の帯**」(見るだけ): この月の配信の状態ごとの件数(未起案 › 承認待ち › 承認済み n / 全体)と「確定した週 n / n」。「確定した週」を押すと、確定していない最初の週の週表示へ。一覧の表示にも同じ帯。
  - **日付のマスを押すと、その日の 10:00 を配信日時にして、新規作成**が開く(マウスを乗せると「＋」が出る)。絞り込み中の国・チャネル・種類も最初から入る。
- **週**: 1 週間の配信を、日ごとに、縮小プレビューつきで並べる(箱の上の帯が、メール = 青、アプリ = ベリー色の塗りつぶしに白抜きの文字・アイコン)。上に、週の状態(と状態ごとの件数)とレビュー・確定の操作を並べた**週の帯**(5.12)。
  - 週の見方「**商品**」は、載せた商品の画像、「**進み具合**」は、工程の進み具合、「**時刻**」は曜日 × 時刻の格子(4.1)を出す。
- **一覧**: 配信を表で並べる。左にサムネイル(マウスを重ねるとプレビュー)。列見出しで並べ替え、表示する列を選べる。**CSV で書き出す**。
- **週・月は、地の部分をつかんで横に引くと、前後の週・月に移る**(トラックパッドの横スワイプでも。右に引くと前、左に引くと次。配信の箱やボタンの上から始めたときは動かない。結果の面の週・月も同じ)。
- どの見せ方でも、配信を押すと、**配信カード**が開く。

### 4.3 配信カードの編集画面(ダイアログ)

**5 つのペイン**で構成する。ペインの境界はドラッグで幅を変えられる(幅は保存される)。

| ペイン | 内容 |
|---|---|
| ① 左: 配信情報 | 青い大きなボタン「**すべてAIで下書き**」。配信名、配信日時、国、チャネル、種類、ステータス、担当者、配信の対象。制作への引き継ぎ(担当・締め切り・引き継ぎ済み)は表示だけで、押すと右端のプロセスのペインの「引き継ぎ」のタブが開く。「工程」として、テーマ・ヘッドライン・コピー(それぞれ、AI の理由・切り口つき)。制作指示は、中ペインの ⑥ で作り、右のプロセスのペインの引き継ぎで確かめる |
| ② 中: コンテンツ生成 | 6つの工程のタブ(メール: テーマ / テンプレート / ヒーロー / セクション / リンク先 / 制作指示。アプリ: テーマ / テンプレート / 通知 / メッセージ / リンク先 / 時刻・相手)。幅に収まらないときは番号(①〜⑥)だけになり、名前はマウスを重ねると出る。下半分に、**AIチャット**。最後に開いたタブを覚える |
| ③ 右: プレビュー | メール / アプリ(通知とメッセージ)のプレビュー。倍率の変更(スライダー、「全体」ボタン) |
| ④ 商品情報 | 掲載商品の参照用の一覧。行を押すと商品のフロート(5.9)。**既定では開いている**(右上の「>」で、細い帯に折りたためる) |
| ⑤ 右端: プロセス | 上に「状態と承認」(承認の依頼・承認・差し戻し。5.12)と「制作の依頼」の札、下に「**引き継ぎ**」「**やり取り**」「**タスク**」「**素材**」のタブ(5.13)。**既定では開いている**(たたむと、状態と未解決の数の細い帯) |

- 題名の左: **チャネルの札**(メール = 青の封筒、アプリ = ベリー色のスマートフォン。週の表示の配信の帯と同じ色)。開いた瞬間に、どちらの配信かが分かる。見るだけ(変えるのは左の「チャネル」)。
- 題名の横: 工程の進み具合「**工程 n / 6**」、送ったあとの配信なら「**結果を見る**」、「**…**」のメニュー(取りやめ・削除)。
- **種類(Type)**(左の配信情報): テーマの種類(値下げ / 期間限定価格 / セール / 新作 / コラボ / 会員向け / 季節の特集 / 再入荷 / その他)。これまでの種別(販促 / CRM / EC)はやめた(データは残す)。「これまでの学び」の帯の種類は見るだけ。種類が決まっていない配信は、⚙ の「種類が未設定の配信を、AI で分ける」でまとめて分けられる。
- **AB テスト**(左の配信情報の「AB テストにする」): 1 つの配信の中に、**A・B・C の 3 案まで**を持つ。A はいまの配信そのもの、B・C は A の写しから始め、**比べる要素(メイン画像 / 商品 / 両方)だけ**を案ごとに変える(それ以外のテーマ・コピー・リンク先・時刻などは全案で共通)。始めると題名の下に帯が出て、**案を切り替える**と、中ペイン・プレビュー・商品情報がその案になる(プレビューに「B 案」などの札)。帯で、**判定の指標**(クリック率・受信者あたりの売上・注文率・開封率。既定はクリック率)、**送り方**(一部に送って勝った案を残りに / 全員を均等に。テストに回す割合と、判定までの時間)、**仮説**を決める。案の追加・外す・AB テストをやめる、も帯から(保存で確定)。B・C 案を開いているときは「**B 案を AI で作る**」で、A 案と違う切り口のメイン画像・商品を AI が選ぶ(仮説があれば、それを確かめられる案に)。「**並べて比べる**」で、案のプレビューを横に並べて見られる。AB テストの配信には、月・週・一覧・時刻の格子で「**A/B**」「**A/B/C**」の印が付く。週の上限(同じ商品を週に何回載せたか)は、B・C 案の商品も数える。承認は全案まとめて 1 回。制作の依頼には、全案の中身とテストの設定がそのまま渡る(制作のページの左の「AB テスト」)。実際に受信者を分けて送るのは、配信システム。
- **案から選ぶ**(左の配信情報の「案を出して選ぶ」): AB テストと同じく A・B・C の 3 案までを作るが、**配信するのは決めた 1 案だけ**。案ごとに、メイン画像・商品・文言(ヘッドライン・コピー・セクションの見出しとコピー・通知の文)のすべてを変えられる(帯の「案ごとに変える」で絞ることもできる)。帯の「**B 案に決める**」で、誰でも決められる(保存で確定)。決めると、その案が配信の中身になり、ほかの案は「**配信しなかった案**」として中身ごと残る(配信カードの上の帯の「配信しなかった案も並べて見る」で見返せる。配信のメモにも残る)。帯の「使い方」で、AB テストと切り替えられる。月・週・一覧の印は、決める前は「A/B?」、決めたあとは「B 案」。
- **配信の対象**(左の配信情報): 性別(指定なし / 女性 / 男性)・年代(指定なし / 10代〜50代以上。複数選べる)・アプリは送る相手(全員 / 会員だけ / 30 日開いていない人 / メールを開いていない人。これまでの工程 ⑥ から移した。アプリの工程は ①〜⑤)。最初に決め、AI の下書き(テーマ・コピー・メイン画像・商品・名前の案)の前提にする。性別が決まっていれば、商品の候補は、その性別とユニセックスの商品だけ(商品の性別は BigQuery の gender)。
- 題名の下: 「**この配信のアラート**」の帯(ふだんは 1 行にたたみ、種類ごとの件数だけ。「見る」で開く。アラートの画面から開いたときは開いた状態。問題の商品を押すと、プレビューで目立ち、そのまま「このアラートへの対応」が開く。行ごとの「対応する」でも開く)、「**これまでの学び**」の帯(同じテンプレート・テーマの種類の、過去の配信のメモ。件数か、そのすぐ右の「見る」を押すと開く)。
- 下: 「キャンセル」「**保存して次へ**」「**保存**」(閉じずに続けて直す。新しい配信は、保存した配信として開き直す)「**保存して閉じる**」。確定した週の配信は、「保存」が「理由を入力して保存」になり、理由が要る。承認の依頼・承認・差し戻しは、右端のプロセスのペイン(5.12)。
- 「保存して次へ」は、保存したあと、閉じずに次の配信を開く。週の表示で確認の一覧の項目を選んでいれば、その項目の配信の中で、それ以外は同じ週の中で、配信日時の順。次がないときは、押せないだけ。
- **AI の案は、保存しない**(画面を開いている間だけ)。保存されるのは、採用した内容と、その補足(理由・切り口)。

### 4.4 結果の面

- 計画の面と同じ見せ方(**月 / 週 / 一覧 / 商品別 / 比べる**)で、送った配信の結果を見る(5.14。商品別は 4.5.1)。見せ方「**効果**」で、配信が売上をどれだけ増やしたかと、AI に渡した学びが効いているかを見る(5.14.1)。
- 配信を押すと、**詳しい結果**が上に重なって開く。
- 月・一覧の上に「**この月**」の要約の帯(配信の数と結果のある数・売上・前月比・前年比・開封率・クリック率。国が混ざるときは、金額と増減を通貨ごとに)。チャネルは、計画の面と同じ塗りつぶしの札(週の箱・一覧の列・詳しい結果の題名の左・比べるの列)。

### 4.5 アラートのフロート

- ヘッダーの「アラート」から、いまの画面の上に重ねて開く。左にアラートの一覧、右に影響を受ける配信と対応の操作(5.15)。

### 4.5.1 商品別(見せ方)

- 見せ方の「**商品別**」。商品を軸に、**自由な期間**(開始〜終了。直近 4 週・直近 12 週・前後 4 週・これから 4 週の近道)の中で、どの配信に何回載せたかと、その結果・売上・外部広告を並べる。計画の面・結果の面のどちらからも使える。
- 粒度は **商品(SPU)/ カテゴリ**(カテゴリの階層の上 2 段。国ごと)。
- 列: 掲載の回数・メール / アプリ・うち予定・最後の掲載・クリック・CTR・**配信経由の売上**(配信の結果)・**期間の売上(全体)**(週ごとの実績)・**外部広告**の日数・費用・費用対効果。
- 印: 週の上限超え、外部広告と重複(7 日以上出稿していて、配信でも 3 回以上)、外部で好調・未掲載(費用対効果 3 倍以上なのに、配信に載せていない)、CTR が低い(2 回以上載せて 1% 未満)。外部に出稿している商品を、配信でも推すべきかを決める材料にする。
- 行を押すと、期間の中の並び(点 = 配信、帯 = 外部広告の出稿)と、載せた配信の一覧(押すと開く)。
- 外部広告のデータは、いまは見本(⚙ の「外部広告の見本を作る」で作り直せる)。本物は、あとで取り込む。

### 4.6 制作の面と、制作のページ

- 面の切り替え **[計画 | 制作 | 結果]** の「制作」。計画・結果と同じカレンダー(配信日)の月・週・一覧で、箱の色は制作の状態、2 行目に状態と締め切り(近い・過ぎたものに印)。承認前の配信は薄く出す。週の「時刻」の見方はない。
- 箱を押すと **制作のページ**(フロート)。左から **要素の情報 | HTML のエディタ | プレビュー | やり取り**(右のペインは、制作のやり取り・**素材**・タスクのタブ)。フロートの大きさとペインの幅は変えられ、覚える。
- 中身は、承認された配信カードの**写し**(承認で下書き、「この内容で依頼する」で固める)。あとで配信カードを変えても、黙って変わらない。企画が変わって承認がやり直しになると「企画が変わりました」と知らせる。
- 要素の情報(文言・メイン画像・商品・リンク先)は項目ごとにコピーでき、**直せる**(承認のやり直しは要らない)。直した行には「企画から変更」の印と元の値を出し、行ごとに戻せる。配信カードと承認された写しは書き換えない。
- HTML は 2 つ: **企画の見本**(配信カードのプレビューと同じ見た目の HTML。見るだけ)と、**制作した HTML**(はじめは企画の見本から始まり、エディタで直すか、制作ツールで作ったものを「**貼り付けて置き換える**」で入れて、版ごとに保存)。エディタの上で切り替える。プレビューは「制作した HTML / 企画の見本 / **並べて比べる**」(2 つを横に並べる)。縮小・拡大と「全体」。
- 「**仕上がりを見る**」(工程の帯の ④ と、配信カードの「制作」の札): 制作した HTML のプレビュー、「制作が終わった」のひとこととできたもののリンク、直してほしいと伝えたこと、制作指示、素材を 1 つのフロートで見る(素材へのコメントもできる)。
- 題名の下の **工程の帯**: ① 制作に依頼する(企画)→ ② 受け取る(制作)→ ③ 制作する(制作。「制作が終わった」に、ひとことと、できたもののリンクを添えられる)→ ④ 仕上がりの確認(企画。「**これで OK**」か「**直してほしい**」。直してほしいことを書くと ③ に戻る)→ ⑤ 配信のしくみに送る(企画)。いまの段のボタンだけを出し、いちばん新しく終えた段は「やり直す」(依頼の段は「依頼を取り下げる」)。制作を通さずに送る近道は「…」のメニュー。
- やり取りは、計画(企画の段階)と制作(制作の段階)で分ける。書き込みに軽いリアクション(👍 了解 / 👀 見ています / ✅ 対応します / 🙏 ありがとう / ❓ 確認したい)。
- 配信カード・制作のページ・詳しい結果の題名の左に **段階の帯**(PLAN → PRODUCTION → RESULTS)。押すと、同じ配信の隣のフロートに切り替える。配信カードのプロセスのペインには「制作の依頼」の札(承認済みで依頼の前なら「次: 制作に依頼する」)。制作のページの「**企画を見る**」で、配信カードを上に重ねて開く(閉じると、制作のページに戻る)。

## 5. 機能の詳細

### 5.1 すべてAIで下書き
- 左ペイン上部のボタン。**テーマ → テンプレート + メイン画像 → ヘッドライン・コピー → 各セクション(見出し・コピー・商品)→ 制作指示**の順に、AI の第1候補で、下書きを作る(アプリの配信は、通知・メッセージの文言)。
- 進み具合が、全画面の「AIが下書きを作っています」で表示される(「スキップして開く」で中断できる)。
- 結果は、**画面に反映するだけで、保存はしない**。気に入らなければ、保存せずに閉じられる。
- 1回で、AI を **6〜9回**呼ぶ(セクションの数による。所要時間は、数十秒程度)。
- 前提: 配信日時が入っていること。
- **自動下書き**: ⚙ の「開いたとき自動で下書き」がオンのとき、**テーマも商品も空のカードを開く**と、自動で下書きを始める(同じカードで1回だけ)。
- 下書きには、「これまでの学び」(過去の配信の、次に生かすメモ)も渡す。

### 5.1.1 まとめて作る(作業画面)
- ヘッダーの「**新規作成 ▾**」→「**まとめて作る**」。全画面の作業画面で、1 週間分の配信をまとめて作る。
- ① **対象と方向を決める**: 週・国・チャネルと、日ごとの配信名・種類(「種類と配信名を AI でまとめて入れる」もある)→ ② **中身を AI で作る**(「作るのをやめる」で止められる)→ ③ **確かめて保存**: 案ごとに「開いて編集」「保存」「破棄」(「破棄を取り消す」)。「この週の中での重なり」も出し、「開いて直す」で直す。
- AI の案は、保存するまで画面だけに持つ。保存したものは、ふつうの下書き(未起案)になる。閉じるときは「まとめて保存して閉じる」か「破棄して閉じる」。「終えて、週の表示で見る」で、その週の週表示へ。

### 5.1.2 週の枠と、まとめて AI で中身を作る
- ヘッダーの「**新規作成 ▾**」の ▾ から「**この週の枠を作る**」(週の表示のときだけ選べる。確定した週では選べない)。「新規作成」の本体は、1 本作るだけ。
- まず、この週に作る配信の、**国とチャネル**を 1 回だけ選ぶ(既定は、画面の絞り込み)。この週の、その国・チャネルの配信がない日(今日以降)が出て、その日に、中身のない配信カード(**枠**。未起案)を 1 本ずつ作る。いらない枠は消せる。
- 枠は、週の表示で、破線の枠と「枠」の印で出る。その場で、**配信名**と**種類**(値下げ・期間限定価格・セール・新作・コラボ・会員向け・季節の特集・再入荷・その他)を入れる(すぐ保存)。配信名は、AI の案を 1 枠ずつ、または帯の「名前のない N 本に、配信名の案を入れる」で、まとめて出せる。
- 配信名と種類が入った枠は、中身を作れる。帯の「**そろった N 本の中身を作る**」「**選んだ N 本の中身を作る**」(枠のチェック)、または枠ごとの「作る」。AI は、配信名と種類に沿って、テーマ・テンプレート・メイン画像・見出し・コピー・商品・制作指示を作る(同時に 3 本まで。すでにある配信とテーマ・商品が重ならないように)。
- 作った中身は保存され、「**AI 下書き・未確認**」の印が付く。印を押すと、右に引き出しが出る。[**中身**]: プレビューと全項目・AI の理由。[**比べる**]: 同じチャネルのすぐ前・すぐ後と、同じ日のもう一方のチャネル(重なる商品は枠、同じテーマは印)。「**確認した**」で印が外れる。「開いて直す」で配信カードを開いて直し、保存しても印は外れる。
- 「確定の前に直すこと」に「未確認の AI 下書き」が出る。承認の履歴に「AI でまとめて作成した」が残る。
- 週の帯の「まとめて依頼」は、中身のない枠を依頼しない。未確認の AI 下書きが入っていれば、依頼の前に知らせる。

### 5.2 ① テーマ(配信全体の前提。メールには出ない)
- 「AIで案を出す」で、テーマの案を **3つ**出す(各案に、理由つき)。ほかの配信と重ならないテーマを出す。
- 案から「採用」を押すと、「現在のテーマ」に入る。採用中の案の**理由**(「AIの理由」)は、保存され、あとで見られる。
- 手で書き換えると、理由は消える(文と理由が食い違わないように)。

### 5.3 ② テンプレート(メールの構成の型)
- 一覧から選ぶ。選ぶと、③④のセクションの構成が変わる。
- **標準のテンプレート 10種**:
  | 名前 | 構成 |
  |---|---|
  | 自由(カテゴリ見出しを自動) | 商品の数に決まりがない |
  | Standard Hero + 4 Grid Items | メイン画像 + 2×2 の商品 4点 |
  | Collaboration Hero + 2 Features + 2 Grid | コラボ用ヒーロー + 特集 2点 + グリッド 2点 |
  | Price: Limited Offer & Value Hero | 赤基調のヒーロー + 価格を強調した 4点 |
  | Standard Hero + 2 Category | カテゴリ 2つ(各 2点)。カテゴリごとに見出し |
  | Standard Hero + 3 Category | カテゴリ 3つ(各 2点)。カテゴリごとに見出し |
  | セール(大きく 1 点 + グリッド) | お知らせ帯 + 文字を大きく重ねたヒーロー。大きく 1 点とグリッドを交互に、最後に写真だけのタイル(12点) |
  | 特集(モザイク + グリッド) | 大 1 点 + 小 2 点のモザイク + 見出し付きグリッド(7点) |
  | ストーリー(写真 + 文) | 写真と商品の説明を左右交互 + 見出し付きグリッド(7点) |
  | コレクション(大きな写真中心) | 大きな写真・モザイク・3 列グリッド(11点) |
- **アプリのテンプレート**(標準 4 つ: お知らせ / 特集 / 商品の紹介 / セール): 「通知の形(テキスト / 画像 / 商品 1 点 + ボタン)」と「メッセージの本文(メールと同じ部品)」の組。
- **セクションの部品**(テンプレートを作るとき): グリッド(2 / 3 列)、写真だけ(2 / 3 列)、大きく(全幅)、モザイク(左が大 / 右が大)、ストーリー、特集。どれにも、見出し(AI が作る)とコピーの有無を決められる。**ボタン**は、セクションとは別の部品で、好きな位置(ヒーローの直後、セクションの間、最後)に 1〜2 個ずつ置ける。ボタンごとに、文言・見た目(塗り / 枠線)・リンク先の種類を持つ。ヒーローは、ヘッドラインの見せ方(帯で重ねる / 大きく重ねる / 写真の下)、画像のリンク先の種類、お知らせ帯を選べる。
- 構成のプレビューは、メールに近い縦長の見取り図で表示する。
- AI も、テーマや時期から、**テンプレートを選べる**(「すべてAIで下書き」のとき)。

### 5.4 ③ ヒーロー(メイン画像 / ヘッドライン・コピー)
- **メイン画像**: 登録済みの画像から、AI がテーマ・季節・用途・タグに合う画像を選ぶ。選定理由つき。候補が3件まで出る。「元に戻す」で戻せる。一覧から手で選ぶ、ドラッグ&ドロップでプレビューに置く、もできる。画像は、国(JP / US)に合うものだけが対象。
- **持っている画像を上げる**(③ の下の「持っている画像を上げる」。AI の案 → 頼み直す → ほかから選ぶ、で合わないとき): 画像(JPEG・PNG・WebP、15MB まで)を置くと、**AI が画像を見て**名前・用途・季節・タグ(テーマ・色・写っているもの)・説明を下書きする(人は確かめて直す)。画像を押して**焦点**(いちばん見せたい場所)を決めると、横長・正方形・縦長に切り出したときの見え方が出て、プレビューでもその点を中心に切り出す。**出どころ**(自社で撮影 / 取引先から / 素材サイトで購入 / その他 と、ひとこと)と**使える期限**も入れる。上げた画像は配信ではなく**メイン画像のライブラリ**に入り、この配信のメイン画像になる。同じ国の次の配信からは、選ぶ候補にも AI の候補にも出る。期限を過ぎた画像は、候補から外れる(使っている配信からは消えない)。
- **メイン画像のライブラリ**(⚙ の「メイン画像のライブラリ」): すべてのメイン画像を一覧(画像・名前・コード・国・用途・季節・タグ・出どころ・使える期限(期限切れ・あと何日)・上げた人・使っている配信の数と今週・前週の数)。言葉・国・上げた画像だけ・期限切れも出す、で絞る。「画像を上げる」(入れる国を選ぶ)、「直す」(名前・用途・季節・タグ・説明・焦点・出どころ・期限)、使っていない画像は「消す」(上げた画像はファイルも)、使っている画像は消さずに「今日で期限を切る」(明日から候補に出ない)。
- **ヘッドライン・コピー**: 「ヘッドライン」(メイン画像の上に載る大見出し)と「コピー」(その下の導入文)を、**組で** 3案出す(各案に「切り口」つき)。言語は、配信の国に合わせる(US は英語、JP は日本語)。「採用」で、両方が反映される。
- プレビューでは、ヘッドラインが**自動で縮小して、1行に収まる**。

### 5.5 ④ セクション(見出し・コピー・商品)
- テンプレートのセクションごとに、**サブタブ**がある(例: グリッド / 特集 / セクション1 …)。
- 各セクションは、3つのブロック: **① 見出し(切り口)**(カテゴリ系のテンプレートのみ)/ **② コピー** / **③ 商品**。
- 「**このセクションをまとめてAIで選定**」で、見出し・コピー・商品を一度に選ぶ。各ブロックにも、「作り直す」「選び直す」がある。
- **商品の選定**: AI が、在庫(少ないものは避ける)、売上トレンド、評価、季節、天候、テーマ、メイン画像・ヘッドラインとの整合などから選び、**理由**を表示する。選定済みの商品と、「残りの候補」(最大3件)が出る。1 つの配信の中で、同じ商品を複数のセクションに入れない。
- 商品の操作(このタブだけで行う): 並べ替え(矢印、ドラッグ)、「外す」(候補へ戻る)、候補の「選ぶ」、理由の編集、**すべての商品から探す**(検索。検索語かカテゴリを指定すると、商品が出る。20件ずつ表示)。
- 商品は、配信カードの**国に合う市場(JP / US)のものだけ**が、AI の対象と検索の対象になる。
- AI の選定結果は、そのまま反映され、「**元に戻す**」で復元できる。

### 5.5.1 ⑤ リンク先
- メール: メイン画像・ボタンごとの URL と、計測用のパラメーター。アプリ: 開くアプリの画面(5.6.1)。詳しくは 5.13。
- リンクの場所すべてに行き先が決まったら、完了(テンプレートの既定の行き先も含む)。「配信カードで指定」のボタンは、配信ごとに決めるまで未完了。

### 5.6 ⑥ 制作指示
- 制作担当に渡す指示文の案を **3つ**出す(各案に、方針の「切り口」つき)。目安は、日本語で200〜240文字。
- 採用すると、左ペインにも反映される。理由・切り口は、保存される。

### 5.6.1 アプリの配信の工程(③ 通知 / ④ メッセージ / ⑤ リンク先)
- **③ 通知**: 通知のタイトル・本文の案を、AI が出す(文字数と上限を表示)。
- **④ メッセージ**: アプリの中のメッセージボックスに届くメッセージ。メールと同じ部品(メイン画像・見出し・セクション)で作る。
- **⑤ リンク先**: 通知は Firebase Cloud Messaging(FCM)で送る想定。開く画面は URL ではなく、通知の data に入れる **screen(画面の名前)と、画面に渡す値**で伝える。
  - 通知を押したときに開く画面: このメッセージ・配信のページ・紹介する商品・カテゴリ・アプリのホーム・画面の名前を指定。
  - メッセージのメイン画像・ボタンごとに開く画面: 既定は、テンプレートのリンク先の種類から決まる(配信のページ → 配信のページ、カテゴリのページ → カテゴリ、ショップのトップ → アプリのホーム)。変えるときは、配信のページ・カテゴリ・商品・ホーム・画面の名前から選ぶ。
  - 商品のリンクは、商品のページ(商品コード)を自動で開く。
  - 各欄の下に、data に入れる値(例: `{"screen":"product","product_code":"…","campaign":"…"}`)を出す。どの画面にも、配信を表す campaign を付ける。
- 送る日時と送る相手(全員・会員など)は、工程ではなく、左の配信情報で決める(送る相手は「配信の対象」の中。最初に決め、AI の下書きの前提にする)。

### 5.7 AIチャット(中ペインの下半分)
- **開いているタブ**の案づくりに、**ユーザーの指示を加える**ためのチャット(「AIチャット — ○○」)。
- 使い方の例: 「もっとカジュアルに」「レインブーツを必ず入れて」「もっと手頃な価格の商品で」「新作を優先して」。入力欄の近くに、**よく使う頼み方**のボタンが出る。
- 動作: 指示を送ると、そのタブの案(または、メイン画像・セクションの選定)が、**指示を反映して作り直される**。AI は、どう直したかを一言で返す。前の指示の条件(「必ず含める」など)は、会話の中で引き継ぐ。
- **質問・相談**(「この商品ラインアップはどう思う?」)のときは、**案を変えずに、答えだけ**を返す。返答の言語は、ユーザーの発言に合わせる。
- 会話は、**タブごと**。画面を開いている間だけ保持する(保存しない)。
- 高さは、上端のつまみのドラッグで変えられる。折りたたみもできる。
- 対象外: **テンプレート**のタブ。

### 5.8 プレビュー(メール / アプリ)
- **メール**: ヒーロー(メイン画像 + ヘッドライン + コピー)、セクションごとの見出し・コピー・商品タイル(画像、名前、価格、ボタン)。テンプレートの構成に従う。メイン画像・ボタンにマウスを重ねると、設定したリンク先が出る。
- **アプリ**: 通知の見た目(iOS / Android の切り替え)と、通知を押したあとのメッセージ。
- **直接編集**: プレビューの上で、セクションの見出しとコピーを書き換えられる。商品のドラッグで並べ替え、ホバーで「前へ / 後へ / 削除」。
- **倍率**: スライダーと、「全体」ボタン(押すと全体が収まる倍率。もう一度押すと **100%** に戻る)。開いたときの既定は「全体」。
- 価格の表記: JP の商品は円(¥)、US の商品はドル($)。

### 5.9 商品情報ペインと、商品のフロート
- 掲載商品を、**メールの並び順**に、セクションごとに一覧する。1行は、画像、名前、「コード・価格・在庫」、売上トレンドの矢印(↑ ↓ →)。**在庫が少ない商品には「残少」**の印。アラートのある商品には種類の札(押すと、そのアラートへの対応)。
- 行にマウスを置くと、プレビューの**該当商品が枠で光る**。
- 行を押すと、**商品のフロート**が開く(画面の真ん中に大きく出し、題名の行をつかんで動かせる。右上の × か Esc で閉じる)。**中ペインの「選定済み」の行を押しても、アラートの札を押しても、同じフロートが開く**(中の行にも「残少」・アラートの札が出る)。アラートから開いたときは、上にそのアラートと「配信日を変える」「アラートの画面で詳しく」が出る(7 章)。
- フロートの左は**差し替えの候補**、右は**詳しい情報**:
  - 左: アラートから開いたときの **AI の差し替え案**、そのセクションの**残りの候補**(中ペインと同じもの・同じ順番)、**ほかの商品を探す**(名前・コード・カテゴリで。「残少」・週の上限・アラートの札つき。もう載っている商品は「掲載済み」)。
  - 右: はじめは、いまの商品の情報。左の商品を押すと、**その商品の情報**に切り替わり、「← いまの商品に戻る」で戻る。理由(任意)を書いて「**差し替える**」と、配信カードの中で入れ替わる(残りの候補を選んだときは、外した商品が候補に戻る)。**保存で確定**し、理由は配信のメモに残る。
- 詳しい情報のタブ:
  - **売上・在庫**: 指標3つ(直近4週の販売数と増減%、在庫が何週分か、12週の売上)、**週ごとの販売数の棒グラフ**、**在庫の推移の折れ線グラフ**(在庫が少ないラインつき)。グラフは12週分。マウスを乗せると、その週の値が出る。
  - **基本情報**: 価格、在庫、売上トレンド、評価、季節、天候適性、説明。
  - **指標**: この商品と、そのカテゴリの週の指標(値・順位・前週比・前月比・前年比)。SKU 欠品率は増えたら赤、在庫数の増減は色なし。まだ取り込んでいなければ、⚙ の「商品・カテゴリの指標を取り込む(CSV)」を案内する。
  - **販売方針・販促**: MD の販売方針、販促の期間、販促計画(週ごとの予定)。位置づけ(主力 / 定番 / 在庫調整 など)がバッジで出る。
- 一覧そのものには、操作する部品を置かない。**差し替えは商品のフロートから、並べ替え・外すは中ペインだけ**。

### 5.10 テンプレートの管理(⚙ の「テンプレートの管理」)
- 左に一覧(「作成したテンプレート」と「標準」。2 列で見比べられる。メールとアプリ)、右に詳細・編集、構成の見取り図(プレビュー)。
- **標準のテンプレートは、編集・削除できない**。「**複製して編集**」で、自分用に作り変える。
- 作成・編集できる内容: **テンプレート名、説明、ヒーロー(種類・ヘッドラインの見せ方・画像のリンク先・お知らせ帯)、構成**。構成は、セクションとボタンの部品を、上から順にカードで並べる(追加・削除・上下の並べ替え)。各セクションで、**商品の並び方**、**商品の枠の数(1〜8点)**、**見出しの有無**、**コピーの有無**を決める。ボタンの部品では、ボタンごとに**文言・見た目・リンク先の種類**を決める。セクションは最大6つ、ボタンの部品は最大8つ。
- リンク先は、テンプレートでは**種類(配信のページ / カテゴリのページ / ショップのトップ / 配信カードで指定)**を決め、実際の URL は配信カードの「リンク先」のタブで決める(5.13)。
- 作ったテンプレートは、**組織の全員が選べる**(アプリのデータベースに保存)。他の人が作ったものも編集できる。
- 削除すると、そのテンプレートを使っていたカードは、Standard4 として扱われる。

### 5.11 日本語 / English
- ⚙ の言語の切り替えで、**画面全体**が、日本語・English になる(初期値は English。選んだ言語はブラウザごとに覚える)。
- **AI の出力**も、画面の言語に合わせる(理由・切り口・制作指示など)。コピー・ヘッドラインは、配信の国の言語で作る(US は英語、JP は日本語)。
- 日付・価格の表記も、言語に合わせる。

### 5.12 週のレビューと承認
- **週の状態**: 確定前 → 確定。状態は、週の帯の左端の印に出す(マウスを重ねると、確定した日時)。
- **週の帯**(週の表示の上。その週のレビューと確定だけを置く): 左端に週の状態の印と、状態ごとの件数(未起案・承認待ち・承認済み。確定は承認済みに数える)。右に「**まとめて依頼**」「**自分宛てを承認**」「**確定の前に直すこと**」の印・「**週を確定**」「確定を取り消す」。
- **配信 1 本ずつの承認**: 配信カードの右端の「状態と承認」で「**承認を依頼**」する(相手は承認グループか人)。承認者には「**承認**」と、理由を付けて「**差し戻す**」が出る(理由はやり取りにも残る)。変更が保存されていないときは、先に「保存」する。「誰が」は右上の「あなた」の人。自分で依頼した配信も、自分で承認できる(確かめてから)。承認のルール(どのグループに回すか)は、すべての配信に同じ 1 つ(⚙ の「ユーザーと承認グループ」→「承認の決まり」)。
- **確定後の変更の制限**: 確定した週の配信では、右のプロセスのペインの状態の下に説明が出る。内容を変えた時点で、上に知らせの帯が出て、保存には理由が必要。保存すると、配信は「検討中」、週は「確定前」に戻り、理由は記録に残る。承認済みの配信の内容を変えても、「検討中」に戻る。
- **確定の前に直すこと**(確認の一覧。「週を確定」の左の印): 週を確定する前に、0 にしておくことの一覧。同じ商品の週の回数(上限を超えたもの)、メールとアプリ、主力の商品の漏れ、テーマ・メイン画像の連続、未解決のやり取り、承認の数。
  - 印は、問題のある項目の数(⚠ と数)。なければ ✓。押すと、一覧が重なって開く(画面は移らない)。
  - 問題のある項目を、**何をするか**(例: 「ほかの商品に差し替える」「質問に返信して、解決にする」)と一緒に出す。問題のない項目は「OK の項目」にまとめ、押すと出る。
  - 項目を選ぶと、週の表示で、かかわる配信・商品が目立つ。帯の左に「選択中: …」の札が出る(× で外す)。「**最初の配信を開く**」から配信カードを開き、「保存して次へ」で、その項目の配信を順に直せる。
  - 残っているまま「週を確定」を押すと、確かめる。
- **承認の履歴**: 誰が・いつ・何から何にしたか(週の操作と、配信のステータスの変更)。「この画面 ▾」の「この週の承認の履歴」。
- **週の資料(PDF)**: 「この画面 ▾」の「週の資料を PDF で書き出す」で、印刷の画面を開く(送り先を「PDF に保存」)。1 枚目に、週の状態・確認の一覧・配信の一覧・承認の履歴。2 枚目からは、配信ごとのプレビュー。

### 5.13 やり取り・引き継ぎ・タスク・リンク先
- 引き継ぎ・やり取り・タスクは、配信カードの右端の**プロセスのペイン**のタブにある。リンク先は、中ペインの「コンテンツ生成」の ⑤。
- **やり取り**: 質問・指摘・相談を書く(以前の「質問」と「コメント」を 1 つにした)。配信全体か、載せた商品を選んで書ける。宛先を入れると、その人に返事を求める(だれからでも、だれにでも)。返信でやり取りし(スレッド)、決着したら「**解決にする**」(「返信して解決にする」もある)。解決したものは消さずに、たたんで残す。未解決の数を、タブ・週の表示・確定の前に直すことに出す。
- **引き継ぎ**: 制作の担当・締め切りを決め(入力はここだけ。左の配信情報は表示)、「制作に知らせる」で引き継ぎ済みにする(アプリからの通知は送らない)。制作のページへの依頼(4.6)と役目が重なるので、どちらを残すかは使ってみて決める。
- **タスク**: 質問などのやり取りから、AI がタスクの案を出し、採用したものを担当・期日・完了で管理する。未完了の数を、タブ・週の表示・一覧に出す。
- **素材(Creative Assets)**: 制作に使ってほしい画像・資料(ファイル。画像・PDF・Office、1 つ 20MB まで)や、参考のページ(URL)を、配信ごとに置く。ファイルは欄に置くか「ファイルを選ぶ」、URL は題名を付けて追加。ひとこと(「この雰囲気で」など)も付けられる。素材を押すと大きく見られ(画像・PDF はその場で。ほかはダウンロード。URL は**見本カード** = ページの題名・説明・代表の画像を、足したときに 1 回だけ取って出す。ページそのものは新しいタブで開く。取り直しもできる)、**その素材についてやり取り**できる(返信・解決は、やり取りと同じ。やり取りの一覧にも「素材: 〜」の札で出る)。だれでも足せて、その場で保存する。消せるのは入れた本人と配信の担当者。一覧は**制作へのメッセージが主役**(1 行に、小さな画像・題名・メッセージの全文・だれがいつ・未解決のコメントの数)。置き場所は、計画では **⑥ 制作指示のタブの下**(「参考の素材」。指示の文章と参考をひと組で添える)と、プロセスのペインの「素材」のタブ、制作のページでは**左の制作指示のすぐ下**と、右の「素材」のタブ。どこも同じものを見る。
- 絞り込みの「担当」は、企画・制作の担当に加え、未解決のやり取りの宛先・書いた人、未完了のタスクの担当の配信も出す。
- **リンク先**(コンテンツ生成の ⑤): メールは、メイン画像・ボタンごとに、実際の URL と計測用のパラメーターを決める。AB テストの配信は、計測用のパラメーターの campaign の末尾に案の印(-a・-b・-c)が付き、案ごとに成果を分けられる(タブには、いま編集している案の値が出る。制作のページでは、案ごとのリンクをまとめてコピーできる)。アプリは、開くアプリの画面を決める(5.6.1)。リンク先のタブを開いている間は、プレビューのリンクの場所に番号が出る(未設定は色が変わる)。

### 5.14 結果の振り返り
- **結果の取り込み**: 結果の面の「この画面 ▾」から、CSV(配信名・配信日・送った数・開封・クリック・注文・売上・前年の売上)を取り込む。「取り込みの見本」もある。CSV で取り込むのは、配信ごとの数字。リンクごとのクリック・商品ごとの結果は、データにあれば、ヒートマップや商品の表に出す。
- **月**: 計画の面と同じカレンダーで、配信ごとに売上・開封率(アプリはタップ率)・前年比。左の線の色は前年比(上なら緑、下なら赤)。結果がまだの配信は灰色。
- **週**: 日ごとに、**クリックを重ねたプレビュー**(ヒートマップ)と主な数字。上に「**この週の振り返り**」のメモ(週全体で気づいたこと・次の週に生かすこと。ふだんは 1 行にたたみ、「書く」「直す」で開いて、その場で保存)。ツールバーの「**先週を振り返る**」で、先週の週表示に 1 回で移れる。
- **前週の振り返り**: 計画の面の週の表示に、前の週に書いた振り返りが出る(「前週の結果を見る」で、結果の面の前週へ)。
- **一覧**: 計画の面と同じ表(左にサムネイル。列見出しで並べ替え)。開封率・クリック率・売上・前週比・前年比。**テーマ / テーマの種類 / テンプレート / 商品**ごとにまとめて見ることもできる。書き出しもできる。
- **比べる**: ツールバーの絞り込みと、テンプレート・テーマの種類・配信名で絞った、直近 5 / 10 / 20 回の配信を、ヒートマップと数字で並べる。AI の評価も出せる。
- **詳しい結果**(配信を押すと上に重なる): 主な数字、プレビューの上に**リンクごとのクリックを濃さで重ねる**(メイン画像・ボタン・商品)、リンクの表、商品ごとのクリック・売れた数と配信の前後の販売・在庫、**販売チャネルごとの順位**(全社・EC・配信経由。配信前 4 週に上位に入った週の数と、配信の週・翌週の順位。上位とみなす線 Top N は変えられ、既定は 60)、採用したテーマ・見出し・テンプレート・メイン画像と AI の理由。
  - **過去の配信と比べる**: 同じテンプレート、または同じテーマの種類の、この配信より前の 3 / 5 / 10 回と、数字・位置ごとのクリックの割合を並べる。
  - **AI で振り返る**: 良かったこと / 悪かったこと / 次に試すこと(数字入り)と、根拠の強さ。1 行ずつ「メモに採用」できる(振り返りそのものは保存しない)。
  - **次に生かすメモ**: 配信ごとに残す。同じテンプレート・テーマの種類の、次の配信カードの「これまでの学び」に出て、AI の案にも渡される。
  - **AB テストの結果**(AB テストの配信だけ): 案ごとの送った数・開封率・クリック率・注文率・1 通あたりの売上を並べ、配信カードで決めた指標で**勝ち案**と、その差が偶然の範囲かの目安(送った数が少ないときは「まだ判断できない」)を出す。勝ち案と仮説の結果は、1 行で「メモに採用」できる。結果の CSV に、案(A / B / C)と区分(テスト分 / 勝ち案の残り分)の列を足して取り込む(省略すると、配信全体の 1 行)。配信全体の数字は、案ごとの行の合計。「案から選ぶ」配信には出さない。
  - 「**制作の詳細**」で配信カードを上に重ねて開ける(閉じると結果に戻る)。「**PDF で書き出す**」で、配信 1 本のレポート(A4 縦 1 枚)。
- **テーマの種類**(値下げ / 期間限定価格 / セール / 新作 / コラボ / 会員向け / 季節の特集 / 再入荷 / その他): 「AI でテーマの種類を分ける」で、まだ決まっていない送った配信を AI が分ける。直すのは配信カード(「これまでの学び」の帯)。詳しい結果では見るだけ(結果を読んでいる途中で、比べる相手が入れ替わらないように)。

### 5.14.1 効果(配信が売上を増やしたか、学びが効いているか)

- 結果の面の見せ方「**効果**」。期間によらず、絞り込みの国・チャネルのすべての配信で見る(少ないと比べられないため)。
- **増えた売上**: 送った人と送らなかった人(ホールドアウト)の、1 人あたりの売上(店舗・EC を含む、配信から 7 日)の差 × 送った人数。**リフト率**は、その差 ÷ 送らなかった人の 1 人あたり。率は国をまたいで比べ、金額は国ごと。詳しい結果の主な数字にも「増えた売上」「リフト率」が出る。
- **学びの記録**: 配信ごとに、AI の依頼に渡した学び(これまでの学び)。表の右に、選んだ配信に渡した学びの中身。詳しい結果にも「この配信に渡した学び」。
- **学びの評価**: 学びごとに、その学びを渡した配信と、渡さなかった配信(同じ国・チャネル、その学びができたあと)の増えた売上を比べ、「残す / 外す / 様子を見る」のおすすめを出す(どちらかが 3 本未満は「材料不足」)。決めるのは人。
- いまは見本のデータ(⚙ の「効果の見本を作る」)。本物のホールドアウトの数字の取り込みは、まだ(9 章)。

### 5.15 アラート
- **在庫切れの見込み・在庫僅少**: まだ送っていない配信に載っている商品について、配信日の在庫を、直近 4 週の販売の速さと、それより前の配信で上乗せされる販売から見込む。配信日に在庫がなくなる見込み、または何週分を切る見込みなら知らせる。
- **MD 方針の変更・日程の変更**: 商品の販売方針・位置づけ・販促の期間、配信日時が変わったら、変更の前と後を知らせる。
- **アラートのフロート**: ヘッダーの「アラート」で、いまの画面の上に重ねて開く(閉じれば、見ていた期間・見せ方・絞り込みのまま)。左に一覧(商品の画像つき。日程の変更は配信の画像)、右に、商品の画像・商品コードと、影響を受ける配信(日付・配信のサムネイル(マウスを重ねるとプレビュー)・チャネル・状態・載っている場所・配信日の在庫の見込み)。ここから開いた配信カードは、さらに上に重なり、閉じるとアラートに戻る。
- **対応**: 配信ごとに、**差し替え**(差し替える商品といまの在庫を上に出し、AI が、配信日に在庫が見込める同じカテゴリの商品を 3 つ提案。候補ごとに、いまの在庫・配信日に何週分・今週と前週に載せた回数)、**開く**(問題の商品を選んだ状態で配信カードを開く)、**延期**、**取りやめ**。変更の理由は記録に残り、確定・承認済みの配信はレビューに戻る。変更のアラートは「対応済み」にできる。
- **対応の記録**: 誰が・いつ・どう対応したか。
- **アラートの条件**: 在庫僅少にする週数(1〜8 週分)・出す種類・対象にする種類(テーマの種類)・担当・**週の上限**(同じ商品を、同じ週に何本の配信まで載せてよいか。既定 2 本。マーケティングの決まりに「上限 週 N 回」があり、配信の国・チャネル・配信日に当てはまれば、そちらが優先。アラート・確認の一覧には「上限 3 本(決まり: 〜)」のように、どこから来た値かを出す)。人ごとに(ブラウザごとに)覚え、ヘッダーの件数にも効く。
- 配信カードの「この配信のアラート」の帯、商品情報とカレンダーの印でも分かる。
- **配信カードの中での対応**: 帯の商品名・「対応する」、プレビューの商品の枠に重なる札(在庫切れ・在庫僅少など。枠が狭いときは印だけ)、商品情報の行の札の、どこから押しても、**商品のフロート**(5.9)が「このアラートへの対応」として開く。在庫のアラートは、左の AI の差し替え案(残りの候補・ほかの商品を探す、からも選べる)を押して右で詳しい情報を確かめ、「**差し替える**」で、その配信の中で商品を置き換える(**保存で確定**。保存しなければ元のまま。差し替えた理由(任意)は、保存のときに配信のメモに残る)。ほかに「**配信日を変える**」(左の配信日時の欄へ)と「**アラートの画面で詳しく**」(その商品のアラートを選んだ状態で開く)。方針・日程の変更は、アラートの画面で確かめて「対応済み」にする。

### 5.16 取りやめ・削除
- 配信カードの題名の横の「…」から。
- **取りやめ**: 理由を残して、消さずに残す。カレンダー・週・一覧に、取り消し線と「取りやめ」の印で薄く出し、アラート・週の確認・件数からは外す。取り消すこともできる。
- **削除**: 間違いで作ったものだけ。元に戻せないことを確かめてから消す。

## 6. AI の仕組み(概要)

- AI は、**Google の Gemini**(Vertex AI)。アプリが、必要な情報(配信の国・日時・テーマ、候補の商品・画像、過去のメモなど)を渡し、AI が**候補の中から選ぶ**・**文案を出す**。商品・画像を作り出すことはない。
- AI を使う場面: 下書き(テーマ・テンプレート・メイン画像・文言・セクション・制作指示・アプリの文言)、まとめて作る、AI チャット、アラートの差し替えの候補、タスクの案、テーマの種類の分類、振り返り、比べるの評価。
- 在庫・売上トレンド・評価・季節・天候・週次の実績・MD の方針・配信の結果は、**アプリのデータベース**に取り込んだデータを元にする。

## 7. データ(初期のサンプルデータ)

動かし始めたときに入っている、架空のサンプルデータ。実際の商品・画像・実績を取り込めば、それに置き換わる。

| データ | 内容 |
|---|---|
| 商品 | JP 30点(円)、US 30点(ドル)。カテゴリ: アウター / トップス / ボトムス / シューズ / 小物 / バッグ / ホーム |
| メイン画像 | JP 20点、US 20点(新作 / 特集 / セール / 会員 / イベント) |
| 配信カード | US 向け・JP 向けの、2026年9〜10月の予定 |
| 週次実績 | 全商品 × 12週(販売数、売上、在庫) |
| 販売方針 | 全商品(MD の方針、販促計画、期間、位置づけ) |
| 配信の結果 | 送った配信の結果(開封・クリック・売上、リンクごとのクリック) |
| 画像 | サンプル用のイラスト(実際の商品写真ではない) |

サンプルデータは、すべて**架空のデータ**。

## 8. 技術(概要)

- ブラウザで使う Web アプリ。画面は React + TypeScript。デザインは **Fluent 2**(Microsoft の UI)。
- サーバーは Python(FastAPI)。データは **PostgreSQL**、AI は **Google の Gemini(Vertex AI)**。
- 同じアプリを、クラウドのサーバーでも、社内のデータ分析環境(ノートブックの環境)でも動かせる。データと画像は、動かす環境ごとに持つ(引っ越し用のファイルで、データと画像をまとめて移せる)。
- 本物のログインは、まだない。右上の「あなた」で選んだ人を、ログインしている人とみなし、承認・やり取りの「誰が」に残す。アクセスは、パスワードなどで守る(動かす環境に合わせる)。

## 9. 未実装・制限(**できないこと**)

- 制作のページの「配信のしくみに送る」は、送り先の窓口だけで、実際にはまだ送らない(送り先のしくみが決まったら、窓口の中を作る)。書き出す HTML は、プレビューと同じ見た目の下書き(表で組んで書式を直接書いた、配信のしくみにそのまま入れる完成品ではない)。
- 商品の性別(配信の対象で商品を絞るのに使う)は、データの側にまだ入っていない環境がある。入っていない商品は、どの対象にも出る。
- **メール・アプリの実配信**は、しない(このアプリは、配信内容の**企画・レビュー・振り返り**まで。配信システムとは連携していない)。結果は、取り込みで入れる。
- **通知**(レビューに出した・引き継いだ、などを、メール・チャットで知らせる)は、しない。
- 商品の売上・在庫・方針・画像は、**取り込んだデータ**を使う。基幹システムとの自動の連携はない。
- 配信カードの**複製**、**変更の履歴**(項目ごとに、いつ誰がどう変えたか)は、まだない(承認の履歴と、配信日・方針の変更の記録はある)。
- **件名・プリヘッダー**、**プレビューの PC / スマホの切り替え**、**月の表示でのドラッグによる日付の移動**(週の「時刻」の見方では動かせる)、**祝日などの予定の重ね合わせ**は、まだない。
- **週の比較画面**(当週と前週を並べる)は、まだない(商品ごとの掲載の回数は、見せ方「商品別」で見る)。
- **AIチャットの会話の保存・再開**はできない(画面を閉じると消える)。**条件のピン留め**(以後のすべてのAI生成に効かせる)も、未実装。
- 承認できるのは、依頼で指名された人と承認グループのメンバーだけ。ただし本物のログインはなく、右上の「あなた」で人を選べば、だれでもその人として押せる。週の状態は、メールとアプリで分けず、週に 1 つ。
- AI の案は、**採用するまで反映されず、保存もされない**(一部の選定は、反映して「元に戻す」)。
- 商品が数千件以上の規模では、読み込み・検索・AI の候補の絞り込みの対策が、今後必要。
- AI の返答は、毎回同じとは限らず、まれに形式が崩れて、自動でやり直すことがある。
- AI の利用には、費用(従量課金)が発生する。
- **効果**の数字は見本だけ(本物のホールドアウト(送らなかった人)の数字は、配信の仕組み・データ基盤と調整してから取り込む)。
- **案から選ぶ**: 承認の画面では案を選べない(配信カードの帯で決める)。「B 案を AI で作る」が選ぶのは、メイン画像と商品だけ(文言は手で直す)。決める前でも、制作に依頼できる(制作のページに注意が出るだけ)。


## 10. デモの流れの例(約10分)

1. **カレンダー**を見せる: 色分け、メールとアプリの見分け、絞り込み(国 = US)、日英の切り替え。
2. 空の配信カードを開く → 「**すべてAIで下書き**」→ 進み具合 → 結果(テーマ、メイン画像、ヘッドライン・コピー、セクションの商品、制作指示)。
3. **プレビュー**: ヘッドラインの縮小、商品のドラッグ。
4. **商品選定の理由**を見せる → **AIチャット**で「レインブーツを必ず入れて」→ 反映 →「どう思う?」→ 答えだけが返る。
5. **商品情報ペイン**を開く → 商品を押す → **売上・在庫のグラフ**、MD の方針。
6. **週の表示**: 確定の前に直すこと → 項目を選ぶ → やり取り → 承認(右端のプロセスのペイン) → 週を確定 → PDF。
7. **アラート**: 在庫切れの見込み → 影響を受ける配信 → AI の差し替えの候補で差し替え。
8. **結果の面**: 月のカレンダー → 詳しい結果のヒートマップ → 過去の配信と比べる → AI で振り返る → メモに採用 → 次の配信カードの「これまでの学び」。
9. **English に切り替え**: 画面と AI の出力が英語になる。
