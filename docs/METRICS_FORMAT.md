# 商品・カテゴリの週の指標の CSV(X48)

商品のフロートの「指標」のタブに出す値を、CSV で取り込む。値は、取り込む前に計算し終えておく(順位・WoW・MoM・YoY まで)。CCP は計算しない。
いまはファイルで渡す。あとで BigQuery から取り込むようにしても、表(`product_metrics` / `category_metrics`)と、この定義は変えない。

- 取り込み方: 画面の ⚙ →「商品・カテゴリの指標を取り込む(CSV)」、または `python -m ccp.cli import-metrics <CSV> --yes`(`--yes` がなければ、確かめるだけ)
- 置き換え: ファイルに入っている **週 × 市場** の行を、まるごと置き換える(ファイルにない週・市場の行は残す)。同じ週を直したいときは、その週の分をすべて入れ直す
- 画面には、商品・カテゴリごとに、いちばん新しい週の行を出す
- 読めなかった行は飛ばし、行の番号と理由を返す(ほかの行は取り込む)
- 引っ越し用のパック(⚙ →「データと画像を書き出す」)に入るので、Workbench にも同じ値が届く

## 1. ファイル

1 行目は列名(順番は自由。余分な列は無視)。UTF-8(BOM はあってもなくてもよい)。商品とカテゴリは、別のファイルにする。

| 列 | 商品 | カテゴリ | 中身 |
|---|---|---|---|
| `week_start` | 必須 | 必須 | 週の開始日(**月曜**。YYYY-MM-DD) |
| `market` | 必須 | 必須 | `JP` / `US` |
| `product_code` | 必須 | — | 商品(SPU)のコード。この列があれば、商品のファイルとみなす |
| `category` | — | 必須 | 商品の `category` と同じ値(`tops` など)。この列があれば、カテゴリのファイルとみなす |
| `metric` | 必須 | 必須 | 項目の名前(2 章) |
| `value` | 必須 | 必須 | 値。金額は、その市場の通貨(円 / ドル) |
| `rank` / `rank_of` | 任意 | 任意 | 順位(1 が上)と、その母数 |
| `wow` / `mom` / `yoy` | 任意 | 任意 | 増減(3 章) |

数字の `,`・`¥`・`$` は外して読む。`%` が付いていれば 100 で割る(`5%` = `0.05`)。空は「なし」(画面では `-`)。

```csv
week_start,market,product_code,metric,value,rank,rank_of,wow,mom,yoy
2026-10-12,JP,P01,ec_sales,1234000,12,240,0.05,-0.02,0.18
2026-10-12,JP,P01,sku_stockout_rate,0.12,,,0.02,-0.01,0.04
```

## 2. 項目

| 対象 | `metric` | 中身 | 順位 |
|---|---|---|---|
| 商品 | `spu_stock` | SPU の在庫数(週の最終日の時点) | なし |
| 商品 | `sku_stock` | SKU の在庫の**合計**(在庫のある SKU の数ではない。週の最終日の時点) | なし |
| 商品 | `sku_stockout_rate` | SKU 欠品率(0〜1)。**週の最終日(日曜)の在庫が 0 の SKU の数 ÷ SKU の数**。分母は SPU の全 SKU(販売を終えた SKU も含める。利用者 2026-10-20) | なし |
| 商品 | `store_sales` | 店舗の売上(その週) | あり |
| 商品 | `ec_sales` | EC の売上(その週) | あり |
| 商品 | `ec_favorites` | EC のお気に入りの数(その週に足された数) | あり |
| カテゴリ | `ec_sessions` | EC のセッション数(その週) | あり |
| カテゴリ | `ec_sales` | EC の売上(その週) | あり |
| カテゴリ | `ec_favorites` | EC のお気に入りの数(その週) | あり |

## 3. 順位と増減の定義(2026-10-20 に利用者と合意)

本物の値を出す人・始める週は、まだ決まっていない。しばらくはダミーの値で使う(利用者 2026-10-20)。

- **順位**: 商品は、**同じ市場の全商品**の中で(カテゴリの中ではない)。カテゴリは、同じ市場のカテゴリ同士で。値の大きい順に 1 から。`rank_of` は、比べた数
- **WoW**: 前の週と比べる
- **MoM**: **暦の月**。週の最終日が入る月の 1 日からその日まで と、前の月の 1 日から同じ日まで を比べる。在庫・欠品率は、週の最終日の値と、前の月の同じ日の値を比べる
- **YoY**: 前年の同じ週(52 週前)と比べる
- 増減の持ち方: 数・金額は割合(`0.05` = +5%)。欠品率は差(`0.02` = +2pt)
- 画面の色: 良くなったら緑、悪くなったら赤。ふつうは増えたら緑。**欠品率は逆**(増えたら赤)。**SPU / SKU 在庫数は色を付けない**(灰色。増えるのが良いとも在庫過多とも読めるので、在庫の持ち・販売と合わせて人が判断する)
