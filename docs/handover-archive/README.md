## 記録の足し方

- 作業の詳しい記録(やったこと・確かめた範囲・残り)は、**いちばん新しいファイルの末尾**に節を足す(見出しは `## 日付 ID 題名(セッション)`)。
- ファイルが 60KB を超えたら、新しいファイル(名前は、最初の記録の日付〜)を始めて、上の表に足す。
- HANDOVER.md の「最近の作業」から押し出した行も、ここの該当する節に残っていることを確かめてから消す。
- このフォルダは、開発元の本番の話を含むので、利用先に渡す Workbench 版の ZIP には入れない(`scripts/release-workbench.mjs` の `RULES`)。
